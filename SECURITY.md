# Security

Please report security problems privately to **info@dailyads.pk** rather than
in a public issue. Include the app version (About screen), what you found and
how to reproduce it. We aim to reply within a week.

The app stores nothing beyond saved ads and recent searches on the device and
talks only to dailyads.pk over HTTPS. Reports about the dailyads.pk website
are welcome at the same address.

To ask for an advertisement or personal information in a published notice to
be removed from dailyads.pk, use the site's
[contact page](https://dailyads.pk/contact).
